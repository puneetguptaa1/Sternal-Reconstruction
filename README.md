# Sternal Reconstruction

Code used to extract, analyze, verify, and visualize data for a meta-analysis of sternotomy and chest-wall reconstruction studies.

## Repository structure

- `analysis/` — data preparation, meta-analysis pipelines, verification, and figure generation.
- `manuscript/` — utilities used to apply controlled edits to manuscript and supplement Word files.
- `data/derived/` — derived data used during manuscript preparation.

## Notes

The scripts represent the analysis workflow used for the paper and expect source workbooks or manuscript files that are not included in this repository. Run analysis scripts from the `analysis/` directory so their relative paths and local imports resolve correctly.
